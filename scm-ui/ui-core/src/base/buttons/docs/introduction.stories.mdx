# Buttons

The `@scm-manager/ui-core` library provides [atoms](https://atomicdesign.bradfrost.com/chapter-2/#atoms) implemented
as minimal wrappers around native html elements styled to match the general SCM-Manager aesthetic.

## Components

There are three actionable components available. Styling is consistent amongst them and all support the optional `variant`
property. Without a variant, they are rendered in the neutral default style.

1. [Button](?path=/story/buttons-button--button)
2. [Link Button](?path=/story/buttons-button--link-button)
3. [External Link Button](?path=/story/buttons-button--external-link-button)

In addition, there are three specialized components:

- [Icon Button](?path=/story/buttons-button--bordered-icon) for actions which are represented by an icon only.
  It has its own variants (`default`, `colored`) and sizes (`medium`, `small`). The button has to declare an
`aria-label` that describes the action (e.g. "Close dialog"), not the icon itself (e.g. not "X"). The icon is decorative
and has to be hidden from screen readers with `aria-hidden="true"`.
- [Icon Link Button](?path=/story/buttons-button--icon-link-button) for links which are represented by an icon only.
  It looks like the medium Icon Button and has the same variants. `aria-label` and `aria-hidden=“true”` must be used (see Icon Button).
- [Unstyled Button](?path=/story/buttons-button--unstyled-button) for clickable elements which must not look like a
  button, e.g. an icon or an entry of a list. If it exclusively contains an icon, `aria-label` and `aria-hidden=“true”` must be used (see Icon Button).

## Usage

Actionable components serve a dedicated purpose. It is therefore important to know when and how to use them.

## Content

Button text should be short, concise and describe the action performed.

Icons tend to be ambiguous and not always applicable which leads to inconsistent and cluttered layouts. An icon may
therefore only complement the text of a button, never replace it. Place the `Icon` component inside the button and wrap
the text in a `span`, so the spacing between icon and text is applied:

```tsx
<Button variant="signal">
  <Icon>trash</Icon>
  <span>Delete</span>
</Button>
```

Actions which can only be represented by an icon use the [Icon Button](?path=/story/buttons-button--bordered-icon)
instead, links use the [Icon Link Button](?path=/story/buttons-button--icon-link-button). As there is no icon-only
variant for external links, an External Link Button which exclusively contains an icon has to declare an `aria-label`.
